## 先用一个生活例子

把项目当成一家小餐馆：

| 地方 | 餐馆类比 | 本仓库 |
|------|----------|--------|
| 菜谱 | 教你怎么做 | `docs/` |
| 试吃窗口 | 马上尝一口 | `examples/` |
| 后厨设备 | 真正可复用的工具 | `src/agent_lab/` |
| 卫生检查 | 自动检查有没有做错 | `tests/` |
| 秘方抽屉 | API 密钥等秘密 | `.env`（不进 git） |

你不会把菜谱和灶台混在一个抽屉里。同理，不要把所有代码塞进一个文件。

## 一步一步讲清楚

### 第1步：你的日常学习路径

```text
读 docs/某节
  → 运行 examples/对应脚本
  → 打开 src/ 对照实现
  → 做练习小改动
  → （可选）pytest
```

### 第2步：为什么是 `src/agent_lab` 这种结构

`agent_lab` 是一个**包名**（package）。  
安装后你可以在任何示例里写：

```python
from agent_lab.models import AgentRequest
```

`pip install -e .` 的 `-e` 表示 editable（可编辑安装）：  
你改 `src/` 里的代码，示例会立刻用到新代码，不必反复重装。

### 第3步：`.env` 是什么

程序需要密钥时，不要写死在代码里（会泄露）。  
惯例如下：

1. 复制 `.env.example` 为 `.env`  
2. 在 `.env` 填真实 Key  
3. 代码通过 `config.py` 读取  

第0章可以先不填 Key。看到相关文件知道用途即可。

## 打开代码一起看（逐行教材版）

打开 `src/agent_lab/config.py`。

### 1）用 Settings 读环境

```python
class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        extra="ignore",  # .env 多写了未知项也不炸
    )
```

Pydantic Settings 会按约定把环境变量映射到字段：  
`OPENAI_API_KEY` → `openai_api_key`（大小写不敏感的常见写法）。

### 2）字段 = 你能调的旋钮

```python
openai_api_key: str = ""
openai_base_url: str = "https://api.openai.com/v1"
openai_model: str = "gpt-4o-mini"
openai_embedding_model: str = "text-embedding-3-small"
agent_lab_host: str = "127.0.0.1"
agent_lab_port: int = 8000
log_level: str = "INFO"
```

| 字段 | 何时用到 |
|------|----------|
| `openai_*` | 第1章起真实调模型 / 第5章 embedding |
| `agent_lab_host/port` | 第10章 FastAPI |
| `log_level` | 日志级别（后续可接 logging） |

### 3）`has_api_key`：有没有真钥匙

```python
@property
def has_api_key(self) -> bool:
    return bool(self.openai_api_key) and not self.openai_api_key.startswith("sk-your")
```

占位符 `sk-your...` 不算有效——所以没配 Key 时示例会走 `--mock`。

### 4）单例

```python
settings = Settings()
```

别处 `from agent_lab.config import settings` 共用一份。

## 常见卡点问答

**Q：我改了 `src` 但示例没变化？**  
A：确认执行过 `pip install -e .`，且你运行的是同一个虚拟环境里的 Python。

**Q：能不能把所有示例代码复制进一个 Jupyter？**  
A：学习阶段可以玩，但本教材以仓库脚本为准，方便你建立工程习惯。

**Q：`.env` 推到 GitHub 了怎么办？**  
A：立刻作废并轮换密钥；把 `.env` 加回 `.gitignore`（仓库应已忽略）。
