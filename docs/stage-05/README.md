# 第5章：RAG——让 Agent 能查你的资料

## 一句话说明

大模型不会自动知道你的私有文档。  
**RAG** = 先检索相关片段，再让模型基于片段回答。

## 先修

- 第3章：理解工具循环（后面会把检索做成工具）
- 第2章：理解「有依据再回答」

## 重要说明（降低挫折）

本仓库第5章默认示例用**本地词法检索**（看词是否重叠），不强制向量数据库。  
这样你零配置也能懂原理。学会后再学 embedding + Chroma。
