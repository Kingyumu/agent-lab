# 第2章：提示词与结构化输出

## 本章要解决什么

第1章你会「让模型说话」。  
但 Agent 开发里，模型经常要输出**程序能用的结果**，例如：

```json
{"goal":"学习Agent","steps":[{"id":"s1","title":"先学工具循环"}]}
```

如果它偶尔输出 Markdown、偶尔少字段，你的程序就会碎。  
本章教两件事：怎么写规矩（Prompt），怎么把输出变成可靠数据（结构化 + 校验）。
