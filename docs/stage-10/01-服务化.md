# 第10章第1节：用 FastAPI 暴露接口

## 写在前面

脚本只能本机跑；服务化之后，前端 / 其他系统才能通过 HTTP 调用你的 Agent。  
本章示例故意做成「教学 mock」：先认清接口形状，再换真 Agent。

## 生活例子

以前只有后厨自己炒菜（脚本）。  
现在开了取餐口：顾客下单（HTTP），厨房做菜（Agent），再取餐（查结果）。

## 本节你将学会

1. `/health`、`POST /runs`、`GET /runs/{id}` 各干什么  
2. 为什么长任务通常先返回 `run_id`  
3. 内存里的 `_RUNS` 为什么不能上生产  

---

## 一步一步讲

常见接口：

| 方法 | 路径 | 作用 |
|------|------|------|
| GET | `/health` | 探活（负载均衡/运维） |
| POST | `/runs` | 创建一个任务 |
| GET | `/runs/{id}` | 查询状态与结果 |

长任务建议：立即返回 `run_id`，后台慢慢跑。  
本章示例为教学方便，**同步 mock 完成**（注释里写了生产应投递队列）。

## 打开代码一起看（逐行教材版）

打开 `src/agent_lab/api/app.py` 与 `src/agent_lab/models.py`。

### 1）请求/响应模型

```python
class AgentRequest(BaseModel):
    session_id: str
    message: str          # 会 strip，空则校验失败
    metadata: dict = {}
    max_steps: int = 8    # 1..30

class AgentResponse(BaseModel):
    session_id: str
    reply: str
    status: RunStatus     # pending/running/succeeded/...
    tool_calls: list[...]
    created_at: datetime
```

对外契约先定死，后面换实现（mock → AgentLoop）不必改调用方。

### 2）内存「数据库」

```python
_RUNS: dict[str, dict[str, Any]] = {}
```

进程一重启全丢；多 worker 也不共享。生产换成 Redis / DB + 任务队列。

### 3）创建运行

```python
@app.post("/runs")
async def create_run(req: AgentRequest) -> CreateRunResponse:
    run_id = str(uuid.uuid4())
    # 教学：同步 mock 完成；生产应投递队列
    resp = AgentResponse(
        session_id=req.session_id,
        reply=f"(api-mock) 已收到：{req.message}",
        status=RunStatus.succeeded,
    )
    _RUNS[run_id] = {"status": ..., "request": ..., "response": ...}
    return CreateRunResponse(run_id=run_id, status=RunStatus.succeeded)
```

读代码时问自己三句：

1. 真 Agent 应挂在哪一行？（替换构造 `resp` 的那段）  
2. 若改成异步执行，首次返回的 `status` 该是什么？（`pending` / `running`）  
3. `req.max_steps` 现在有没有传给 Loop？（还没有——留给你接）

### 4）查询与探活

```python
@app.get("/health")
def health(): ...

@app.get("/runs/{run_id}")
def get_run(run_id: str):
    if run_id not in _RUNS:
        return {"error": "not_found"}
    return _RUNS[run_id]
```

### 5）怎么启动

`examples/stage10_api_demo.py`：

```python
uvicorn.run(
    "agent_lab.api.app:app",

```

```powershell
python examples/stage10_api_demo.py
```

