## 一步一步讲

### Agent 特有风险

1. 提示注入驱动高危工具  
2. 工具权限过大  
3. 密钥/隐私进日志  
4. 随便接入不明 MCP Server  

### 最低要求 ↔ 本仓库

| 要求 | 落点 |
|------|------|
| 密钥只放环境变量 | `config.Settings` + `.env`（勿提交） |
| 工具白名单 | `ToolRegistry` 只注册你允许的工具 |
| 副作用分级 + HITL | `ToolSpec.side_effect` / `require_confirmation`；第6章 HITL 流 |
| 日志脱敏 | `StepTrace` 落盘前去掉 key/cookie（待你加） |
| 代码执行进沙箱 | 本仓库不提供任意代码执行工具——保持这样 |
| 审计 | `run_id` + steps + 谁调用了 API（API 层待加鉴权） |
| Prompt 安全句 | `prompts/react_agent.txt` 第 6 条 |

**只靠 Prompt 不够**：必须工具权限 + HITL + 评测里的拒绝题（`refuse_1`）一起上。

### API 面额外注意

- 不要把 `openai_api_key` 回传到响应  
- `/runs` 要鉴权，否则谁都能刷你的账单  
- 用户 `message` 长度已有上限（`max_length=20_000`），继续收紧也可以
