# 第8章第3节：怎么选框架（决策课）

## 写在前面

选型不是选「最火的」，而是选「你缺的能力、团队能运维的复杂度」。  
本仓库故意：**核心能力手写，框架只作对照**。

## 本节你将学会

1. 一张决策表：需求 → 更合适的栈  
2. 用本仓库已有实现当「证据」做选型  
3. 为毕业小项目写清「哪段手写、哪段上 Graph」  

## 决策表

| 你的需求 | 更合适 |
|----------|--------|
| 学原理、面试、排障 | 自研 Loop（本仓库第3章） |
| 复杂分支 / HITL / 持久化 | LangGraph |
| 快速做文档索引实验 | LlamaIndex |
| 快速多角色原型 | CrewAI / AutoGen（了解即可） |
| 最薄上线 | 官方 SDK + 清晰状态机 |

## 原则

1. 先自研，再框架  
2. 框架加速，不替代理解  
3. 上线看：评测、权限、可观测、可回放  

---

## 打开代码 / 仓库对照（选型证据）

打开这些「已经存在的实现」，当作选型证据，而不是广告文案：

| 能力 | 本仓库落点 | 说明 |
|------|------------|------|
| Tool Loop | `agent/loop.py` | 无框架也能跑 |
| 结构化计划 | `planning/plan_execute.py` | 用了 `complete_structured` |
| HITL | `planning/hitl_flow.py` | 手写状态机 |
| 校验 | `agent/verifier.py` | 规则出门检 |
| 图编排示例 | `examples/stage08_langgraph_demo.py` | 可选依赖 `[graph]` |
| 占位说明 | `src/agent_lab/frameworks/__init__.py` | 提醒先完成第3章 |
| 路线打印 | `examples/stage08_framework_notes_demo.py` | 无额外依赖 |

运行对照说明：

```powershell
python examples/stage08_framework_notes_demo.py
```

你会看到：

```text
自研 AgentLoop → 官方 SDK → LangGraph →（可选）LlamaIndex
```

### 如何写「10 行选型理由」（模板）

```text
1. 问题类型：……
2. 是否需要工具循环：是/否
3. 步骤是否大体固定：……
4. 是否需要 HITL：……
5. 手写部分：AgentLoop / 工具 / 评测
6. 框架部分：仅 ……（或「暂不上框架」）
7. 评测：smoke.jsonl 会覆盖……
8. 权限：工具白名单 + ……
9. 观测：StepTrace / 日志字段……
10. 回退方案：框架去掉后仍可用 SDK+Loop
```

---

## 动手做

1. （必做）为你的下一个小项目按上面模板写 10 行选型理由。  
2. （必做）明确一句：哪一段会用手写、哪一段才上 Graph（可以是「全部手写」）。

## 小结 / 第8章收束

你会在「手写」和「框架」之间切换了——切换的依据是治理与复杂度，不是潮流。
