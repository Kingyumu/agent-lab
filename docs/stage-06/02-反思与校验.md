# 第6章第2节：校验器（先规则，后模型评判）

## 写在前面

校验器 = 最终回答出门前的安检。  
优先用规则；LLM-as-Judge 以后再加。

## 生活例子

出门前照镜子：衣服扣错了就重扣。

## 一步一步讲

1. **规则校验**：非空、最短长度、必须含引用…  
2. **LLM 评判**：让模型打分（不稳，需人工抽检）  
3. 失败 → 把 `reasons` 回灌 Agent 重试（限次）

## 打开代码一起看（逐行教材版）

打开 `src/agent_lab/agent/verifier.py` 与 `examples/stage06_verifier_demo.py`。

### 1）返回值

```python
@dataclass
class VerifyResult:
    ok: bool
    reasons: list[str]  # 失败原因列表，可直接塞回 Prompt
```

### 2）规则如何叠加

```python
def verify_final_answer(text, *, require_citation=False):
    reasons = []
    if not text or not text.strip():
        reasons.append("答案为空")
    if len(text.strip()) < 5:
        reasons.append("答案过短")
    if require_citation and not re.search(r"\[[\w\-#\.]+\]", text):
        reasons.append("缺少引用（期望类似 [doc#0]）")
    return VerifyResult(ok=not reasons, reasons=reasons)
```

多条规则**不互斥**：可以同时「过短 + 缺引用」。

### 3）演示在测什么

```powershell
python examples/stage06_verifier_demo.py
```

三条样例大致是：带引用通过 / 无引用失败 / 空串失败。
