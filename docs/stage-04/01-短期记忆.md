# 第4章第1节：短期记忆（当前会话）

## 写在前面

短期记忆 = **这一次聊天窗口里**，模型下一轮还能看到的内容。

它不是神秘大脑，通常就是：

- 最近若干条 messages，或
- 「旧对话摘要 + 最近几条原文」

---

## 本节你将学会

1. 为什么不截断会出问题（又贵又超窗口）
2. 滑动窗口是什么
3. 摘要压缩是什么

---

## 生活例子

你和朋友连续聊了 2 小时。  
下次开口不可能把两小时录音全文再放一遍，通常是：

> 我们刚才聊到你下周要面试，重点是项目经历。

这就是摘要；再补上「刚刚最后两句原文」。

---

## 一步一步讲

### 第1步：Tool Agent 会让历史膨胀得很快

每一轮工具调用都额外增加 assistant/tool 消息。  
不加管理，成本上升，模型还可能忘掉早期 system 约束。

### 第2步：滑动窗口

只保留最近 N 条。简单，但可能丢掉早先关键事实。

### 第3步：摘要 + 窗口（常用）

```text
[摘要：用户叫小明，在学 Agent]
[最近几条原文消息]
```

本仓库用 `ConversationMemory.compact_with_summary` 演示结构；真实摘要可由模型生成。

---

## 打开代码一起看（逐行教材版）

打开 `src/agent_lab/memory/conversation.py` 与 `examples/stage04_memory_demo.py`。

### 1）三件套字段

```python
@dataclass
class ConversationMemory:
    session_id: str
    messages: list[ChatMessage] = field(default_factory=list)  # 原文消息
    summary: str | None = None  # 压缩后的「旧对话摘要」
```

### 2）`add`：只负责追加

```python
def add(self, message: ChatMessage) -> None:
    self.messages.append(message)
```

不在这里截断——截断是显式策略，避免悄悄丢数据。

### 3）`get_context`：真正送给模型看的内容

```python
recent = self.messages[-max_messages:]  # 滑动窗口：只要最后 N 条
if not self.summary:
    return list(recent)
return [
    ChatMessage(role="system", content=f"此前对话摘要：{self.summary}"),
    *recent,
]
```

有摘要时：`[摘要 system] + [最近原文]`。  
注意：这里的摘要 system **不是**最初那份「角色规则」；生产里常把规则 system 固定放在最前。

### 4）`compact_with_summary`：压缩

```python
self.summary = summary
self.messages = self.messages[-keep_last:]  # 只留最后几条原文
```

教学版摘要由你传入字符串；真实项目可再调一次 LLM 生成 summary。

### 5）演示在观察什么

```powershell
python examples/stage04_memory_demo.py
```

先塞很多轮消息 → `get_context(max_messages=6)` 变短 → `compact_with_summary` 后再看首条是否变成摘要。

短期记忆管理的是「当前会话上下文成本与完整性」的平衡。
