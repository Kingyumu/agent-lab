# 第4章：记忆与断点恢复

## 本章要解决什么问题

第3章的 Agent 一次问答很棒，但现实里还有两件事：

1. **多轮对话**：用户上一句说「叫我小明」，下一句还希望你记得  
2. **长任务中断**：执行到一半程序挂了，希望能继续而不是从头来

本章就学这两类「记住」。
